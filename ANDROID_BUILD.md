# Сборка APK для Lucky Casino (Windows + WSL)

Что входит в набор:

- `buildozer.spec` - настройки сборки (название, иконка, портретный режим, какие файлы класть в APK)
- `build_android.sh` - скрипт, который сам копирует проект, собирает APK и кладёт результат в папку `apk`
- `assets/android/icon.png` и `presplash.png` - иконка и заставка (в стиле игры)
- `make_android_assets.py` - перегенерация иконки и заставки (нужен Pillow, для сборки не обязателен)

Код игры менять не нужно: кошелёк уже сохраняется в `user_data_dir`, а размер окна 400x700 ставится только на компьютере.

## Что понадобится

- Windows 10/11, интернет и свободное место на диске C: около 20 ГБ (SDK, NDK и кэш сборки скачиваются при первой сборке)
- Желательно 8 ГБ оперативной памяти
- Время: первая сборка может идти долго, последующие быстрее

## Шаг 1. Установить WSL2 и Ubuntu (один раз)

1. Откройте PowerShell **от имени администратора** (только для этого шага).
2. Выполните: `wsl --install -d Ubuntu-24.04`
3. Перезагрузите компьютер, если попросит.
4. При первом запуске Ubuntu придумайте имя пользователя и пароль. Пароль нужен для `sudo`, запомните его.
5. Проверка: в PowerShell `wsl -l -v`. У Ubuntu в колонке VERSION должно стоять **2**.

## Шаг 2. Поставить системные пакеты (один раз)

Откройте Ubuntu (меню Пуск -> Ubuntu) и выполните:

```
sudo apt update
sudo apt install -y git zip unzip openjdk-17-jdk python3-pip python3-venv autoconf libtool pkg-config zlib1g-dev libncurses-dev cmake libffi-dev libssl-dev build-essential rsync
```

Если какого-то пакета нет, актуальный список для вашей версии Ubuntu смотрите на https://buildozer.readthedocs.io/en/latest/installation/

## Шаг 3. Запустить сборку

В Ubuntu выполните (путь замените на папку с вашим проектом; диск D: в Linux это `/mnt/d`):

```
sed -i 's/\r$//' /mnt/d/main/Казик/build_android.sh
bash /mnt/d/main/Казик/build_android.sh
```

Первая строка нужна на случай, если Windows поменяла переводы строк в скрипте. Если путь с русскими буквами вызывает ошибки, скопируйте проект в папку с латинским названием, например `D:\main\kazik`.

Скрипт сам:

1. создаст окружение с buildozer (один раз)
2. скопирует проект в `~/kazik_build` (на диске Linux, так нужно)
3. соберёт APK
4. положит файл в папку `apk` рядом с проектом

Не закрывайте окно Ubuntu, пока идёт сборка. Если сборка оборвалась, просто запустите скрипт снова: уже скачанное не качается заново.

## Шаг 4. Поставить на телефон

1. Скопируйте файл из папки `apk` на телефон (кабель, Telegram себе в "Избранное" и т.п.).
2. Откройте его на телефоне. Android попросит разрешить установку из этого источника: разрешите.
3. Это debug-версия для себя. Для публикации в магазине нужна другая сборка (release с подписью).

## Если что-то пошло не так

| Проблема | Что делать |
|---|---|
| `bad interpreter` или `\r` в ошибке | Выполните `sed -i 's/\r$//' build_android.sh` и запустите снова |
| Buildozer пишет, что не хватает пакета | Поставьте его через `sudo apt install -y <пакет>` и запустите скрипт снова |
| Ошибки про Cython | В Ubuntu: `~/buildozer-venv/bin/pip install "cython<3"` и запустить снова |
| Странные ошибки после неудачной сборки | `rm -rf ~/kazik_build/.buildozer` и запустить снова |
| Не хватает места | Освободите диск C:, потом повторите |
| Ошибка "SDK license" | В `buildozer.spec` уже стоит автоматическое принятие, запустите ещё раз |

Если сборка падает, пришлите мне **последние 50-100 строк лога** из окна Ubuntu. Без начала лога причину часто не видно.

## Что проверить на телефоне

- Игра открывается в портретном режиме на весь экран
- Звуки есть и кнопка с нотой (значок звука в блэкджеке) работает
- Баланс сохраняется после закрытия и повторного открытия
- Фон стола, анимации и карты не тормозят
- Кнопка "Выход" в меню закрывает приложение

## Важно

- Я не мог собрать APK сам: у меня нет доступа к Android SDK и сети. Файлы подготовлены по документации Buildozer, но при первой сборке могут понадобиться поправки.
- В `buildozer.spec` версия Kivy закреплена как `2.3.0`. Если у вас на компьютере другая (`pip show kivy`), игра могла проверяться на ней: при странностях сообщите, поменяем.
- Не запускайте Ubuntu и сборку от администратора Windows. Пароль `sudo` нужен только для `apt install`.
